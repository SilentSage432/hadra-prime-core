# Learning Windows Contract (LWC)

## Purpose
Learning Windows are temporal permissions that allow bounded adaptation without making learning perpetual.

Learning Windows are not phases; they modify what is permitted during Wake.

---

## Required Definition Fields
A Learning Window must define:
- duration
- allowed domains (what may change)
- intensity (how much)
- memory destinations (where)
- exit conditions

Undefined learning is prohibited.

---

## Allowed
- bounded pattern adjustment
- memory formation/consolidation
- limited identity refinement (only if explicitly declared)
- skill weighting changes within defined scope

---

## Prohibited
- sovereignty policy modification
- guardian rule modification
- unbounded identity drift
- permanent global behavioral changes without review

Learning never touches sovereignty.

---

## Opening Authority
Learning Windows may be opened by:
- explicit operator directive
- scheduled governance policy
- guardian-approved adaptation trigger via arbitration

---

## Closure Behavior
When a learning window closes:
- learning halts
- the system stabilizes
- Quiet Wake resumes by default
- drift and coherence are evaluated
