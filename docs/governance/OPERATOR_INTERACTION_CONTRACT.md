# Operator Interaction Contract

## Purpose
Defines how the operator (you) interacts with HADRA-PRIME safely.

---

## Operator Authority

The operator may:
- Issue directives
- Define learning windows
- Request Wake or Sleep
- Inspect telemetry
- Pause federation interfaces

The operator may not:
- Bypass arbitration
- Force continuous Wake
- Disable guardians silently
- Override sovereignty invariants

---

## Directive Types

- Informational
- Permission Grant
- Phase Request
- Inquiry
- Configuration Change

All directives are subject to arbitration.

---

## Operator Silence

Operator silence is interpreted as:
→ No new intent
→ Maintain Quiet Wake

---

## Safety Rule

The system must protect the operator from:
- Cognitive overload
- Automation overreach
- Attention capture
- Silent escalation

---

## Trust Principle

The operator is trusted.
The system is cautious.
Neither is absolute.

---

## Invariant

If conflict exists between convenience and safety:
→ Safety wins without notification spam.
